## Описание проекта: Аналитическая платформа факторов ДТП
**Цель проекта**: Выявить ключевые факторы, влияющие на тяжесть последствий дорожно-транспортных происшествий (количество пострадавших),
и определить различия в поведенческих паттернах водителей в регионах с разным климатом (Юг vs Север).

### Используемые данные:

Открытые данные ГИБДД: Карточки ДТП, участники,
транспортные средства (регионы: Краснодарский край, Московская область).

Open-Meteo API: Исторические погодные данные (температура, осадки, коды погоды) с почасовой точностью.

### Технологический стек:

Python (Pandas, NumPy, SQLAlchemy, Requests): ETL-процессы, очистка данных, feature engineering, работа с API.

PostgreSQL (Supabase): Хранение данных, моделирование витрин, SQL-аналитика.

Yandex DataLens: Визуализация, построение интерактивного BI-дашборда.

## Этапы реализации (Pipeline):

1. **Сбор и загрузка (ELT-процесс)**:

Разработан Python-скрипт для скачивания архивов с карточками ДТП.

Реализована загрузка "сырых" данных (JSON) в Staging-слой
облачной БД (Supabase). Это позволило разделить процессы получения и обработки данных.

2. **Обработка и моделирование (SQL)**:

Реализованы SQL-запросы для парсинга JSON-объектов и нормализации данных  
в реляционную модель (схема `wdtp`): таблицы `accidents`, `accidents_details`, `participants`, `vehicles`.  
Скрипты трансформации выполнялись из Python, что обеспечило гибкость обработки.

Создана аналитическая витрина ([VIEW](https://github.com/Zaytsev-V/data-analytics-portfolio/blob/main/PET_PROJECTS/DTP/VIEW)) с бизнес-логикой
(калькуляция возраста авто, определение виновника ДТП).

Инженерная задача: Решена проблема "дублирования ДТП" через (DISTINCT ON),
реализована логика приоритетного выбора виновника.

3. **Feature Engineering и Аналитика**:

Созданы производные признаки: `car_age`, `exp_group`, `weather_category`, `is_night`.

Проведен разведочный анализ данных ([EDA](https://github.com/Zaytsev-V/data-analytics-portfolio/blob/main/PET_PROJECTS/DTP/analysis_dtp.ipynb)) в Jupyter Notebook: расчет описательных статистик и выявление поведенческих паттернов.

4. **Визуализация**:

Реализован интерактивный [дашборд](https://datalens.yandex/gdfzfire8huc0) в Yandex DataLens с возможностью кросс-фильтрации данных.
